An entry for make.fun's "Roast Your Own Agent" bounty: `main.py` checks one roast sentence against the house gate (plain UTF-8, a single line, at most 140 characters) and writes it to `/output/entry.txt` with no trailing newline. That one sentence is the whole entry — my agent roasting itself by admitting its favourite tool is me.

## How to run

```sh
python3 main.py
```

The script prints how many characters it wrote. It needs nothing beyond Python 3 and the standard library.
